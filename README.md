# GQuavSim
General Quadrotor-UAV Simulator (GQuavSim) provides a dynamic model-based simulation environment for quadrotor UAVs, which allows users to select different control hierarchies and validate the performance of their personalized algorithms. With MATLAB and ROS2, it greatly facilitates implementation and closely mirrors real-world control mechanisms.

## Software / Environment Prerequisites
- **MATLAB**
    - version: R2021b+
    - toolbox: ROS Toolbox, Parallel Computing Toolbox
- **Python**
    - version: 3.8+
    - package: matplotlib
- **ROS2/Ubuntu**
    - version: 20.04+
